# Incident Lifecycle

## Lifecycle

```text
Open
  ↓
Investigating
  ↓
Contained
  ↓
Eradicated
  ↓
Recovered
  ↓
Closed
```

## Open

Incident has been reported and requires assessment.

Required:

* Incident ID
* Title
* Category
* Initial owner
* Detection timestamp

## Investigating

The security team is actively determining:

* Scope
* Root cause
* Impact
* Affected assets
* Affected users
* Required containment

## Contained

The immediate threat has been controlled.

Examples:

* Account disabled
* Endpoint isolated
* Malicious traffic blocked
* Compromised system isolated

## Eradicated

The underlying cause has been removed.

Examples:

* Malware removed
* Vulnerability patched
* Credentials reset
* Persistence removed

## Recovered

Systems have been restored and validated.

Requirements:

* Security validation
* Monitoring
* Business confirmation

## Closed

The incident is formally closed after:

* Recovery
* Documentation
* Stakeholder notification
* Corrective action tracking
* Post-Incident Review where required
