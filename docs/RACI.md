# Incident Response RACI Matrix

## Purpose

This RACI framework defines accountability and responsibility across the
incident response lifecycle.

RACI:

- **R — Responsible:** performs the activity.
- **A — Accountable:** owns the final outcome.
- **C — Consulted:** provides expertise or input.
- **I — Informed:** must be kept informed.

## Governance Principle

Every major incident must have:

1. A clearly identified Incident Commander.
2. A defined accountable executive owner.
3. Explicit technical responders.
4. Appropriate Legal/Privacy involvement when regulatory obligations may exist.
5. Documented communication responsibilities.
6. A formal post-incident review before closure.
